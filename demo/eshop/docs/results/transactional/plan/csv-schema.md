## 1. Column Schema

| Column       | Type   | Required | Format / Constraints           | Source      |
| ------------ | ------ | -------- | ------------------------------ | ----------- |
| email        | String | Yes      | Valid email format             | credentials |
| password     | String | Yes      | >=8 chars, uppercase, special  | credentials |
| product_id   | Number | Yes      | ID of existing product in DB   | db_seeded   |
| product_name | String | Yes      | Name of existing product in DB | db_seeded   |
| price        | Number | Yes      | Price of product in DB         | db_seeded   |
| quantity     | Number | Yes      | Default to 1                   | db_seeded   |

**Column sources:**

- `credentials` = generated by `seed-data.js` during registration and written to CSV
- `db_seeded` = real product created by `seed-data.js` and read back from the API
