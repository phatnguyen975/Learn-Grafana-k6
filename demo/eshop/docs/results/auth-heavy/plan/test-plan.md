### Think Time

**Value:** 0.75 seconds (randomised: 0.5 - 1.0s)

**Reasoning:** 0.5–1 second is the standard think time for a stress test. It is shorter than a load test because the goal is to find the breaking point efficiently by pushing load, not strictly simulating realistic user pacing.

### Abort Conditions _(stress and spike tests only)_

| Condition   | Threshold | Action                         |
| ----------- | --------- | ------------------------------ |
| Error rate  | > 10%     | `abortOnFail: true`, delay 30s |
| p95 latency | > 200 ms  | `abortOnFail: true`, delay 30s |

_(Note: The **SLO threshold** for error rate is 5% (meaning the test is officially considered "degraded" if it crosses 5%). However, the **Abort condition** is set higher at 10% to allow the stress test to push past the initial degradation point and confirm a hard break, rather than stopping prematurely at a minor spike)._
